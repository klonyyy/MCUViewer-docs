# Building locally

`jupyter book start` (or `npx jupyter-book build --html` for a one-off build that reports broken references)

# Screenshots

Screenshots are of size 1326x1032 (the MCUViewer window, title bar included) or a dialog cropped out of it.
They are generated by the scripts in [tools/screenshots](tools/screenshots/README.md) - every image has a spec in
`tools/screenshots/specs` and the `.drawio` file next to the image is generated from it.
